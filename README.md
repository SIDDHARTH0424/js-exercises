# JavaScript Exercises

10 exercises covering arrays, objects, functions and the DOM.

- `arrays.js`: exercises 1 to 3
- `objects.js`: exercises 4 and 5
- `functions.js`: exercises 6 and 7
- `index.html` + `dom.js`: exercises 8 to 10

Run Node files with `node arrays.js` etc. Open `index.html` in a browser for the DOM ones.
